# 🚀 Starfleet Command — UC4

Sistema de gerenciamento e controle de uma frota espacial desenvolvido em **TypeScript**, com foco na aplicação prática dos principais conceitos da **Programação Orientada a Objetos (POO)**.

O projeto simula diferentes tipos de naves espaciais e suas respectivas funções dentro de uma frota, permitindo realizar operações de **combate, exploração, transporte de cargas, reparo, gerenciamento de recursos e controle das naves**.

---

## 🌌 Sobre o projeto

O **Starfleet Command** foi desenvolvido para representar, de forma prática, um sistema de gerenciamento de uma frota espacial.

A aplicação utiliza uma estrutura orientada a objetos para representar diferentes tipos de naves, cada uma possuindo características e responsabilidades próprias.

O sistema foi projetado utilizando conceitos como:

- 🧱 Classes e objetos
- 🔒 Encapsulamento
- 🧬 Herança
- 🎯 Abstração
- 🔌 Interfaces
- 🔄 Polimorfismo
- 🛡️ Modificadores de acesso
- 📦 Organização modular
- ⚙️ Validação de dados
- 🚀 Gerenciamento de recursos

A ideia principal é permitir que diferentes tipos de naves compartilhem comportamentos comuns, enquanto cada classe especializada possui suas próprias funcionalidades.
